# Права пользователей системы

## Оператор ЦОДД
В панельке может:
1. Получать информацию о Подрядчике/ах
2. Изменять информацию о Подрядчике
3. Добавлять подрядчика
4. Возможно добавлять работников подрядчика(но наврное это должен делать подрядчик)
5. Удалять подрядчика
6. Получать информацию о Шкафе/ах
7. Изменять информацию о Шкафе/ах
8. Добавлять Шкаф
9. Удалять Шкаф
10. Получать информацию о Заявках на обслуживание
11. Оставлять комментарии к заявкам

> мб надо формирование отчетности какой-то?  
> надо ли цодд получать данные со шкафов?

## Оператор подрядчика
1. Получить инфо о шкафе/ах
2. Получить список своих работяг
3. Добавить/удалить/редактировать работягу
4. Посмотреть заявки (фильтры по работяге, статусу, шкафу)
5. назначить исполнителя из списка своих работяг

>Наверное заявка после выполнения работягой должны подтверждаться подрядчиком и потом идти в цодд\
>А зачем нам вообще ЦОДД?

## Оператор исполнителя(работяга)
1. Принимает заявку на работу
2. Просматривает заявки/у на работу
3. Отмечает в заявке, что приступил к работе (получает код, что-то с ним делает, шкаф открылся, работает ...)
4. Может оставить комментарий к заявке
5. Завершает заявку с каким-то статусом (все сдела, замечний нет| не сделал нужна помощь)

> А кто формирует заявки на обслуживание? Наверное ЦОДД просит обслужить шкаф подрядчика
